# Pressroom

A small, automated pipeline that turns a curated list of RSS feeds into a daily static newspaper page with a synthesized editorial.

## What it does

1. **Scrape** – fetches the RSS feeds listed in `data/feeds.yml`, filters articles by publication date, and writes `data/filtered_entries.yml`.
2. **Parse** – ranks articles by semantic similarity to the reader profile in `data/readers_interests.md`, diversifies sources, reranks the top candidates with an LLM for diversity and importance, assigns theme and country tags to each selected article ("international" if multiple countries are concerned), translates non-French text to French, generates a French editorial, extracts a headline with a cheap LLM, and writes `data/parsed_entries.yml`.
3. **Prepare** – classifies the parsed articles into thematic sections of ~`section_size` articles each (1–2 word titles), using only the title, themes, and countries to keep costs low, and writes `data/prepared_entries.yml`.
4. **Speak** – synthesizes the editorial to `data/editorial.mp3` via OpenRouter's TTS API.
5. **Render** – generates `press_room.html`, a responsive black-and-white newspaper page grouped by the editorial sections, with the headline and current weekday at the top.

## Requirements

- Python 3.12
- Conda (the project uses a Conda environment, not venv)
- An OpenRouter API key (stored in `config.py`)

## Setup

1. Create and activate the Conda environment:

```bash
conda create -n press_room python=3.12 pyyaml feedparser requests -y
conda activate press_room
pip install wordllama openrouter
```

2. Add your OpenRouter API key to `config.py`.

3. Adjust `data/feeds.yml`, `data/readers_interests.md`, and `config.py` to your needs.

## Running the pipeline

To generate today's issue from scratch:

```bash
conda activate press_room
python run_pipeline.py
```

`run_pipeline.py` imports a well-chosen function from each step and calls them in sequence:

- `feed_reader.scrape_feeds()`
- `parse_feed.parse_and_export()`
- `prepare_entries.prepare_and_export()`
- `editorial_to_mp3.generate_editorial_mp3()`
- `gen_static_page.generate_page()`

You can also run each step individually:

```bash
python feed_reader.py
python parse_feed.py
python prepare_entries.py
python editorial_to_mp3.py
python gen_static_page.py
```

## Serving the page

Start the built-in static server:

```bash
conda activate press_room
python serve.py
```

By default the server binds to `0.0.0.0` and is available at `http://localhost:8080/` as well as from other machines on the network. Change the port in `config.py` (`SERVE_PORT`) or with `--port`:

```bash
python serve.py --port 3000
```

To bind to a specific interface only, use `--host`:

```bash
python serve.py --host 127.0.0.1
```

The page checks every 30 seconds whether `press_room.html` has changed and reloads automatically, so you can leave the server running while `run_pipeline.py` updates the issue.

## Deployment with cron

To publish a fresh issue every day, schedule `run_pipeline.py` with cron. Example for 6:00 AM daily:

```bash
# Edit your crontab
crontab -e
```

Add a line like this (adjust the conda activation path and project directory to your machine):

```cron
0 6 * * * /opt/homebrew/Caskroom/miniconda/base/bin/conda run -n press_room python /Users/admin/Documents/Projects/press_room/run_pipeline.py >> /Users/admin/Documents/Projects/press_room/pipeline.log 2>&1
```

Leave `serve.py` running as a long-lived service (e.g. via a process manager or a second cron entry with `@reboot`) so the latest generated page is always accessible.

## Customization

- **Number of articles:** edit `DEFAULT_CANDIDATES_COUNT` and `DEFAULT_FINAL_COUNT` in `config.py`.
- **Section size:** edit `DEFAULT_SECTION_SIZE` in `config.py` to control how many articles each thematic section groups.
- **Source diversity:** edit `DEFAULT_MAX_PER_SOURCE` in `config.py` to cap candidates per newspaper before LLM reranking.
- **Models:** edit `DEFAULT_MODEL` (reranking/translation/title extraction), `FANCY_MODEL` (editorial), and `DEFAULT_SECTION_MODEL` (section classification) in `config.py`. The default slugs include `:nitro` for faster inference on OpenRouter.
- **TTS voice:** edit `DEFAULT_VOICE` in `editorial_to_mp3.py`.
- **Styling:** edit `templates/page.html` and `templates/article.html`.

## Notes

- `run_pipeline.py` prints the duration of each step and the total runtime.
- The extracted headline and current weekday are displayed at the top of `press_room.html` in a large, responsive font.
